# Support moving tickets between projects

Should be able to move tickets within a repo between the projects/sub-projects.
Should be able to move with a button from the view ticket screen or by drag and drop.

Projects need a config button that allows renaming or moving, or the drag and drop.

Moving should renumber the ticket to the latest in that set.
