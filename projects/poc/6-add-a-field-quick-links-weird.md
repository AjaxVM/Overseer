# Add a field quick links weird

Now that we have default fields, add a field is funky. I do like being able to specific "default" fields that always are added (ie `id` is system added, not configurable, but status, estimate, etc. whatever the user adds some should just be added to all new tickets, though they need to default to a null value until set manually (or add those to the initial creation as required fields).

Add field quick links should only appear for defined fields NOT already present on the ticket.
