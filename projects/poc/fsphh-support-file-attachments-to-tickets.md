# Support file attachments to tickets

This is an after the fact ticket capturing the work to support attachments.
Currently we will support markdown and jpg/jpeg/png images only.
There is an ability to associate local files (copy with new name), or create a new markdown file.
Files have the filename convention of `<frontmatter:id>.attachment.<attachment name>.md` and live alongside their tickets.

Markdown can be edited or previewed.
